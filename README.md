# AI 生成视频素材管理仓库

面向个人创作者的 Web 素材仓库，用于保存 AI 视频及生成信息，支持分类、检索、预览和下载。

当前完成需求分析，后续按确认后的需求进行系统设计与开发。

## 文档

- [需求分析 Markdown](2024337621128_郑子渲_需求分析.md)
- [需求分析 Word](2024337621128_郑子渲_需求分析.docx)

## 首期功能

1. 素材上传与维护。
2. 模型、提示词及生成来源追溯。
3. 项目与标签管理。
4. 组合检索、视频预览与原文件下载。
5. 素材数量与容量统计。

范围暂按多账号、各账号私有管理确定，直接调用视频生成 API 列为后续扩展。
